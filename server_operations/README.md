# Приложение "Обслуживание серверов"

Django-приложение для управления операциями технического обслуживания серверного оборудования (Вариант 27 контрольной работы).

## Описание

Приложение разработано в соответствии с требованиями контрольной работы и демонстрирует полный цикл работы с данными без использования Django ORM:

**SQLite → SQL → Python `sqlite3` → Django view → context → Django templates → HTML/CSS/JavaScript**

## Функциональность

### Основные страницы:
1. **Главная страница** (`/`) - обзор приложения и навигация
2. **Стойки** (`/racks/`) - список серверных стоек
3. **Операции** (`/operations/`) - список операций с фильтрацией и сортировкой
4. **Статистика** (`/operations/statistics/`) - статистика по типам операций
5. **Детальная информация** (`/operations/<slug>/`) - полная информация об операции

### Ключевые особенности:
- Использование только SQL-запросов (без Django ORM)
- GET-фильтрация операций по количеству узлов
- Сортировка и ограничение выборки (ORDER BY, LIMIT)
- Статистические запросы с GROUP BY и HAVING
- Обработка ошибок (404, ошибки БД)
- Использование шаблонных фильтров Django
- Подключение статических файлов (CSS, JavaScript, изображения)

## Установка и запуск

### 1. Установка зависимостей
```bash
pip install django
```

### 2. Инициализация базы данных
```bash
cd server_operations
python init_database.py
```

### 3. Применение миграций Django
```bash
python manage.py migrate
```

### 4. Запуск сервера разработки
```bash
python manage.py runserver
```

### 5. Доступ к приложению
Откройте браузер и перейдите по адресу: `http://127.0.0.1:8000/`

## Технические особенности

### Работа с базой данных
Приложение использует модуль `sqlite3` Python для прямого доступа к базе данных. Все SQL-запросы параметризованы для безопасности.

Пример параметризованного запроса:
```python
query = "SELECT * FROM operations WHERE nodes >= ?"
params = (min_nodes,)
execute_query(query, params)
```

### Шаблонные фильтры Django
Используются 5 шаблонных фильтров:
1. `date` - форматирование даты
2. `default` - значение по умолчанию
3. `length` - подсчет элементов
4. `upper` - верхний регистр
5. `truncatechars` - ограничение текста

### Статические файлы
- `static/css/style.css` - собственное оформление
- `static/js/main.js` - интерактивные элементы
- `static/img/logo.png` - логотип приложения

SQL-запросы для статистики

Основной запрос (используется на этой странице):

SELECT 
    op_type,
    COUNT(*) as count,
    AVG(duration) as avg_duration,
    SUM(nodes) as total_nodes,
    SUM(CASE WHEN status = 'выполнена' THEN 1 ELSE 0 END) as completed_count
FROM operations
GROUP BY op_type
HAVING COUNT(*) > 0
ORDER BY count DESC

GROUP BY op_type — группировка по типу операции
COUNT(*) — подсчет количества операций в каждой группе
HAVING COUNT(*) > 0 — фильтрация групп (только те типы, у которых есть операции)
ORDER BY count DESC — сортировка по количеству операций по убыванию

Другие статистические запросы:

Статистика по статусам
SELECT status, COUNT(*) FROM operations GROUP BY status
Операции по стойкам
SELECT r.name, COUNT(o.id) FROM racks r LEFT JOIN operations o ON r.id = o.rack_id GROUP BY r.id
Среднее по узлам
SELECT AVG(nodes) as avg_nodes FROM operations

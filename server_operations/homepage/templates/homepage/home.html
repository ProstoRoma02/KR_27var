О приложении

Это Django-приложение демонстрирует полный цикл работы с данными:

  1. SQLite → SQL → Python sqlite3 → Django view → context → Django templates → HTML/CSS/JavaScript
  2. Используются только SQL-запросы без Django ORM
  3. Реализована фильтрация через GET-параметры
  4. Поддержка сортировки и ограничения выборки с помощью ORDER BY и LIMIT
  5. Обработка ошибок и корректные HTTP-ответы
  6. Использование статических файлов и шаблонных фильтров Django
